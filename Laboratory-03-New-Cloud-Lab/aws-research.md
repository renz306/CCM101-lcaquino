# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides various services for computing, storage, networking, databases, and security. It allows users and organizations to access cloud resources without maintaining physical servers.

## Global Infrastructure

AWS has a global infrastructure made up of **Regions** and **Availability Zones**. These locations help organizations deploy applications in different areas and improve system availability and reliability.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to create, configure, monitor, and manage AWS services and resources.

## Four Core Services

### 1. Amazon EC2

Amazon EC2 provides virtual servers that users can use to run websites, applications, and other workloads in the cloud.

### 2. Amazon S3

Amazon S3 is an object storage service used to store files, images, documents, backups, and other types of data.

### 3. Amazon VPC

Amazon VPC provides a private virtual network where AWS resources can communicate securely.

### 4. AWS IAM

AWS IAM manages users, roles, and permissions. It helps control who can access specific AWS resources and services.

## Three Advantages

* Scalable and flexible cloud resources
* Reliable global infrastructure
* Wide range of cloud services

## Typical Enterprise Use Cases

AWS can be used by businesses to host websites and applications, store and back up data, manage databases, perform data analysis, and build scalable cloud infrastructure.
