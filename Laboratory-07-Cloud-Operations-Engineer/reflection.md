# Reflection

This activity taught me how important it is to monitor a server and check if it has enough resources to run applications properly. I learned that CPU, memory, and disk usage should be checked to avoid problems that may affect the containers.

I also learned how to use Docker commands to check application logs. These logs help identify errors and understand what happened when an application does not work as expected.

Another thing I learned is that logs and metrics have different purposes. Logs show events and errors, while metrics provide information about system performance. Both are helpful when monitoring and troubleshooting applications.

I also understood that monitoring tools like Prometheus and Grafana can help manage many containers more easily. They allow engineers to view system information and identify possible problems.

Overall, this activity improved my knowledge of Linux commands, Docker, and server monitoring. I learned that proper monitoring and troubleshooting are important skills for keeping applications stable and running smoothly.
