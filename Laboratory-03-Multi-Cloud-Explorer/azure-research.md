# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, security, and application development. It helps organizations build, deploy, and manage applications through the cloud.

## Global Infrastructure

Azure has a global infrastructure consisting of **Regions** and **Availability Zones**. These locations allow organizations to deploy applications closer to their users and improve reliability and availability.

## Cloud Management Portal

The **Azure Portal** is a web-based interface used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual computers that can be used to run applications, websites, and other workloads in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage is a cloud storage service used to store files, images, videos, backups, and other unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network provides a private network environment that allows Azure resources to communicate securely with each other and with external networks.

### 4. Microsoft Entra ID

Microsoft Entra ID manages user identities and access to Azure resources. It helps organizations control authentication, users, groups, and permissions.

## Three Advantages

* Flexible and scalable cloud resources
* Global cloud infrastructure
* Wide range of cloud services

## Typical Enterprise Use Cases

Azure can be used by businesses to host websites and applications, store and manage data, run virtual machines, manage databases, create backups, perform analytics, and build enterprise cloud solutions.
