# Reflection

During this laboratory activity, I gained a better understanding of the three major cloud platforms: AWS, Microsoft Azure, and Google Cloud Platform (GCP). I learned that each platform offers different services for computing, storage, networking, databases, and security. I also realized that cloud platforms make it easier for organizations to use computing resources without depending entirely on physical servers.

One of the things I learned from comparing the platforms is that they have similar services but different strengths. AWS provides a wide selection of cloud services and flexible resources. Azure is useful for organizations that already use Microsoft technologies, while GCP has strong capabilities in data analytics, artificial intelligence, and machine learning. This helped me understand that there is no single cloud platform that is best for every organization.

I also learned that choosing a cloud provider should be based on the actual needs of the client. Factors such as budget, security, existing systems, performance, scalability, and future requirements should be considered before making a recommendation. Different clients may require different platforms depending on their business goals and technical requirements.

This activity also helped me understand the role of a Cloud Solutions Consultant. I learned that the job involves analyzing a client's situation, comparing available cloud services, and selecting solutions that can properly address their needs. It is important to understand both the advantages and limitations of each cloud platform before making a decision.

Lastly, creating and organizing my files in GitHub helped me improve my documentation and technical skills. I learned how to use Markdown files to present research, comparisons, recommendations, and reflections in an organized way. Overall, this laboratory activity improved my knowledge of cloud computing and gave me practical experience that I can apply to future IT projects.
