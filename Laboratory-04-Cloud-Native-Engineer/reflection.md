# Mission Reflection

This activity helped me understand how Docker containers are managed throughout their lifecycle. I learned that containers can be checked, stopped, verified, and removed using simple Docker commands. These commands make container management easier and more organized.

Using `docker ps` allows me to see which containers are currently running. I also learned that `docker stop nginx-server` can stop a specific container without removing it immediately. After stopping the container, I can use `docker ps -a` to check its status and confirm that it is no longer running.

The `docker rm nginx-server` command taught me that stopping a container and removing a container are different processes. A stopped container can still exist in Docker until it is manually removed. Removing unused containers can also help keep the Docker environment clean and organized.

This activity also showed me how Docker can simplify application deployment. Instead of managing an entire operating system, Docker allows applications to run inside lightweight containers. This makes it easier to start, stop, and manage applications in different environments.

My GitHub portfolio is improving because this laboratory adds practical Docker skills to my previous cloud computing activities. It documents my experience with container management, Linux commands, and deployment. This activity helped me become more familiar with tools that are commonly used in cloud and IT environments.
