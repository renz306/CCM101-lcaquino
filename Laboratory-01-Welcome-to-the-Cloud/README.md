## Linux Commands Used

* pwd – Shows the current location in the file system.
* ls – Displays the files and folders in the current directory.
* cd – Allows navigation between directories.
* mkdir – Creates new directories.
* touch – Creates new files.
* cat – Shows the text stored inside a file.
* nano – Allows editing of files through the terminal.
* ls -R – Shows directories together with the files contained inside them.
