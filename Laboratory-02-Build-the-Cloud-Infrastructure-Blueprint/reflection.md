# Checkpoint 7 – Mission Reflection

## Mission Reflection

### 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the **network** is the most important cloud infrastructure component because it connects the different resources and allows them to communicate with each other. Without a properly configured network, users may not be able to access applications, storage, or other cloud services. A secure and reliable network also helps protect cloud resources from unauthorized access.

### 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, secure, and flexible operating system for cloud servers and virtual machines. Many cloud environments use Linux because it is lightweight, reliable, and can be managed efficiently through the command line. Linux commands also allow administrators to manage files, processes, users, networking, and system resources.

### 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear plan of how the infrastructure should be configured and operated. It helps developers and administrators understand the resources, connections, commands, and procedures involved. Good documentation also reduces errors, makes troubleshooting easier, and allows other team members to maintain or update the infrastructure.
