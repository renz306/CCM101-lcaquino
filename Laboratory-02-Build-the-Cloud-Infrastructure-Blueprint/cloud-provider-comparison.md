# Checkpoint 4 – Research the Major Cloud Providers

## Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID + Azure RBAC | Google Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS offers the broadest overall range of cloud services among the three major providers. It provides many services for compute, storage, networking, databases, security, analytics, AI/ML, and other specialized workloads.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it integrates closely with Microsoft products and technologies. Organizations using Windows Server, Microsoft 365, and Microsoft Entra ID can easily connect their existing systems with Azure services.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform (GCP) is widely recognized for its strengths in Artificial Intelligence, Machine Learning, and Kubernetes services. Google created Kubernetes and provides Google Kubernetes Engine (GKE), along with various AI and ML services.

### 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer similar core infrastructure services, including virtual machines for computing, object storage, virtual networking, and identity and access management. They provide scalable, secure, and flexible cloud services that can support both small projects and large enterprise applications.
