# Reflection – Cloud Automation Engineer

In this laboratory activity, I learned how Bash scripting and Cron can help automate cloud management tasks. I discovered that automated backups can save time and reduce the need to perform repetitive commands manually. This makes system maintenance more convenient and organized.

I also learned that automation must be used carefully. Incorrect commands or file locations can cause problems, especially when handling important data. Testing the script before running it regularly is important to make sure that it works as expected.

Compared to Docker Compose in Laboratory 6, Bash scripting focuses on executing commands and automating tasks, while Docker Compose manages multiple containers and their configurations. Although they have different purposes, both tools help make technical tasks easier and more efficient.

Throughout Laboratories 1 to 9, I gained more knowledge about cloud computing, including infrastructure, deployment, containers, security, monitoring, and automation. Each activity helped me understand the tools used by cloud engineers and how they support reliable systems.

Among the roles I explored, I enjoyed being a Cloud Automation Engineer because I learned how to create scripts that perform tasks automatically. This activity improved my scripting skills and taught me the importance of accuracy, testing, and data protection. Overall, I realized that automation makes cloud operations more efficient when it is properly planned and managed.
