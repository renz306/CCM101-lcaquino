# Reflection: The Cloud Security Engineer

In this laboratory activity, I learned how to protect a server using UFW firewall in Ubuntu. I learned how to allow necessary connections, block unwanted traffic, and manage open ports. These steps help make the server more secure.

I also understood the importance of the Principle of Least Privilege and the Default Deny policy. These security practices help prevent unauthorized access by allowing only the connections that are needed.

I realized that leaving ports open, especially database ports like MySQL port 3306, can be risky. It is better to allow access only to trusted users and systems to protect important data.

This activity taught me that server security is an important part of managing cloud infrastructure. Proper firewall settings and regular security checks can help reduce possible threats. As an IT student, I can use these lessons in future projects and improve my knowledge of cloud security.

Overall, this mission gave me a better understanding of how firewalls protect servers. Completing this activity also helped me gain more experience in using Linux commands and applying basic security practices.
