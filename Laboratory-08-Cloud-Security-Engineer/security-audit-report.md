# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

This principle means giving users only the access they need to perform their work. It helps protect important data and reduces the risk of unauthorized access to the system.

## 2. Attack Surface

The attack surface includes all the possible ways someone could try to access a server. Open ports and unnecessary services may create security risks. Disabling unused services and closing unneeded ports can help protect the server.

## 3. Default Deny Policy

The Default Deny policy blocks incoming connections unless they are allowed by firewall rules. This helps prevent unwanted access and allows only necessary services to communicate with the server.
