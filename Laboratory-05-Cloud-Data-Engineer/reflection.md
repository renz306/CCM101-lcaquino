# Mission Reflection

This activity helped me understand how Object Storage can be used to manage a large number of files. I learned that it is useful for unstructured data such as photos, videos, documents, and backups. Instead of treating each file like a normal folder-based file system, Object Storage uses buckets and objects to organize the data.

I also learned that Docker can make the deployment of MinIO much easier. Instead of going through a long installation process, I was able to run the storage server using a Docker command. Configuring the ports and login credentials through the command also helped me understand how containers can be configured before they are started.

Creating a bucket in MinIO gave me a better idea of how cloud storage organizes files. The bucket acts as a storage area where objects can be placed and managed. Uploading a sample file allowed me to see how the process works in an actual object storage environment.

Data availability is also important for companies that store large amounts of information. Hardware can fail, so having backups and copies of important data can help prevent permanent data loss. Using multiple storage locations or servers can also help keep data accessible when problems occur.

Overall, this mission improved my confidence in using the Linux terminal and Docker. I became more comfortable entering commands, checking containers, and working with MinIO. Some commands were unfamiliar to me at first, but doing the activity step by step helped me understand them better. This experience gave me additional knowledge that I can use in future cloud computing and IT activities.
