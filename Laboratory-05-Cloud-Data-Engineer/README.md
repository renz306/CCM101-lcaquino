# Laboratory 05 - Cloud Data Engineer

## Laboratory Overview

This laboratory activity explores the use of cloud-based object storage through **MinIO**. The activity demonstrates how an object storage service can be deployed inside a Docker container and accessed through its web interface. It also covers the basic process of creating a bucket and storing files as objects.

## Learning Objectives

By completing this laboratory, the following skills and concepts were practiced:

* Identify the basic concepts of Block Storage, File Storage, and Object Storage.
* Understand how Object Storage handles unstructured files and digital assets.
* Set up MinIO using Docker.
* Configure and run a MinIO container.
* Access the MinIO Console using a web browser.
* Create and organize data using storage buckets.
* Upload files and manage objects within MinIO.
* Apply Docker and Linux commands in a cloud laboratory environment.
* Document the completed activity using Markdown and GitHub.

## Technologies and Platforms

The following tools and platforms were used during the laboratory:

* **KillerCoda** – Provided the Linux-based practice environment.
* **Ubuntu** – Served as the operating system for executing the required commands.
* **Docker** – Used to create and manage the MinIO container.
* **MinIO** – Provided the object storage service for the laboratory.
* **MinIO Console** – Used for managing buckets and uploaded objects.
* **GitHub** – Used to organize and publish the laboratory documentation.
* **Markdown** – Used for preparing the README documentation.

## Laboratory Tasks

The laboratory involved several activities related to object storage:

1. Review the different types of cloud storage.
2. Prepare the Ubuntu environment in KillerCoda.
3. Run the MinIO Object Storage service through Docker.
4. Configure the required MinIO credentials and ports.
5. Open the MinIO Web Console.
6. Create a new bucket for storing objects.
7. Upload a sample file into the bucket.
8. Verify that the uploaded object is available.
9. Document the completed steps and results in the GitHub repository.

## Skills and Knowledge Gained

After completing the activity, I gained practical experience in:

* Understanding the role of Object Storage in cloud computing.
* Deploying applications through Docker containers.
* Working with MinIO as an S3-compatible storage platform.
* Using Docker commands in a Linux environment.
* Managing buckets and objects.
* Accessing containerized applications through mapped ports.
* Performing basic cloud storage operations.
* Creating organized technical documentation.
* Using GitHub as a portfolio for cloud computing activities.

## Conclusion

The laboratory provided hands-on experience with cloud object storage using MinIO and Docker. Through the activity, I learned how storage services can be deployed in a containerized environment and managed through a web console. The exercise also improved my understanding of buckets, objects, Docker configuration, and basic cloud storage management.
