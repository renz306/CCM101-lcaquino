# Types of Cloud Storage

## Cloud Storage Comparison

| **Type**           | **Description**          | **Use**                         | **Example** |
| ------------------ | ------------------------ | ------------------------------- | ----------- |
| **Block Storage**  | Stores data in blocks.   | Databases and virtual machines. | AWS EBS     |
| **File Storage**   | Stores files in folders. | Shared documents and files.     | AWS EFS     |
| **Object Storage** | Stores data as objects.  | Photos, videos, and backups.    | Amazon S3   |

## Why Object Storage?

Object Storage is a good choice for a photo-sharing application because it can store many images and other files. It is also easy to organize and can handle more data as the application grows.
